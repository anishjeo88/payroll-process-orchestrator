rule-based router (`interface/pages/2_Agent_Chat.py::handle()`) rather than
failing:

`cycle_summary()` - the same grounded facts, formatted deterministically
instead of by Claude.

**Q: Why is Benefits Data Feed Validation delayed?** → routed to
`why_this_delay()`, which queries the same Historical Cycle Store record
directly.
